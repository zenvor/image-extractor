Browse images with steadier sidebar controls and find, filter and clean up download records more easily.

## Popup refinements

- Download task and More each occupy a full-width row.
- Image-type filters open in a scrollable popover without pushing other controls around.
- Simpler extraction-scope guidance and loading skeletons make startup clearer.

## Download records

- See each task’s creation date and time.
- Search by title, filename or source URL and filter by task status.
- Delete individual finished records or clear all completed records while keeping downloaded files.
- Filtering keeps active downloads running; active records cannot be deleted.

## Updated interface gallery

The README now shows the current English and Chinese interfaces using a curated WhatsApp homepage example, plus the source webpage and download manager. Task screenshots use demonstration records. WhatsApp imagery belongs to its respective owners; no affiliation or endorsement is implied.

## Download and update

Requires **Chrome 120 or newer**. Finish active downloads before updating.

- [Chrome extension ZIP](https://github.com/zenvor/image-extractor-extension/releases/download/v1.2.1/image-extractor-1.2.1-chrome.zip)
- [SHA-256 checksum](https://github.com/zenvor/image-extractor-extension/releases/download/v1.2.1/image-extractor-1.2.1-chrome.zip.sha256)

Extract the ZIP, then use `chrome://extensions` → **Developer mode** → **Load unpacked**, or replace the files in your existing unpacked installation and select **Reload**. Source code archives are not the installation package.

No new permissions. This GitHub release does not update the Chrome Web Store package automatically.
