Browse images with steadier sidebar controls and find, filter and clean up download records more easily.

## Popup refinements

- Download task and More each occupy a full-width row.
- Image-type filters open in a scrollable popover without pushing other controls around.
- Simpler extraction-scope guidance and loading skeletons make startup clearer.

## Download records

- See each task’s creation date and time.
- Search by title, filename or source URL and filter by task status.
- Delete individual finished records or clear all completed records while keeping downloaded files.
- Filtering keeps active downloads running; active records cannot be deleted.
