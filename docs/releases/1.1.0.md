Find original images behind supported image-host links in ViperGirls posts and accessible mirrors. This release adds image-detail lookup alongside the existing thumbnail URL rules.

## What's new

- **More ways to reach originals.** Read supported image-detail pages linked by thumbnails, including links from the current webpage and imported HTML.
- **Eleven image-host families.** IMX, Imgbox, Vipr, Pixhost, ImageBam, Imagevenue, TurboImageHost, Acidimg, ImageTwist, Imgspice, and Postimages / Pixxxels.
- **Keep your choices.** Completed matches are saved without selecting images automatically. Closing the popup or starting a new extraction cancels unfinished lookups.
- **Controlled requests.** Detail lookups share request limits and server cooldown with downloads. Access to the relevant image hosts is requested when needed.

## Try it

1. Open a supported forum page and load the images you want.
2. Open Image Extractor and enable **Match original images**. Grant image-host access if prompted.
3. Select the matched images and choose **Download selected**.

This resolves images on the loaded page; it does not automatically traverse an entire thread. Website verification, expired links and rate limits can prevent a match. See [supported formats and compatibility notes](https://github.com/zenvor/image-extractor/blob/v1.1.0/docs/hosted-images.md).

## Download and update

Requires **Chrome 120 or newer**.

| File | Purpose |
| --- | --- |
| [Chrome extension ZIP](https://github.com/zenvor/image-extractor/releases/download/v1.1.0/image-extractor-1.1.0-chrome.zip) | Ready-to-load extension package |
| [SHA-256 checksum](https://github.com/zenvor/image-extractor/releases/download/v1.1.0/image-extractor-1.1.0-chrome.zip.sha256) | Verify the downloaded ZIP |

For a first installation, extract the ZIP and load its folder through `chrome://extensions` → **Developer mode** → **Load unpacked**. For an existing unpacked installation, finish active downloads before replacing its files and selecting **Reload**. The **Source code** archives are not the installation package.
