The first stable release of Image Extractor: a free Chrome extension to find webpage images, choose what to save, and download your selection as a ZIP.

## Highlights

- **Preview and choose.** Browse images in a grid or list, filter by format or text, and select images yourself. New results start unselected.
- **Find supported originals.** Match thumbnail URLs on IMX, Imgbox, Pixhost, Vipr, Duitang and other supported sites to original-image addresses.
- **Process several sources.** Extract from the current page, batches of webpage URLs, or saved HTML files. Copy selected URLs or export a TXT list.
- **Manage downloads together.** Track downloads from several pages in one place, adjust request limits, retry failed images, and resume interrupted tasks when cached files are available.
- **Use either language.** English and Simplified Chinese interfaces, with no account or payment required.

## Download and install

Requires **Chrome 120 or newer**.

| File | Purpose |
| --- | --- |
| [Chrome extension ZIP](https://github.com/zenvor/image-extractor-extension/releases/download/v1.0.0/image-extractor-1.0.0-chrome.zip) | Ready-to-load extension package |
| [SHA-256 checksum](https://github.com/zenvor/image-extractor-extension/releases/download/v1.0.0/image-extractor-1.0.0-chrome.zip.sha256) | Verify the downloaded ZIP |

Extract the extension ZIP to a folder you will keep. Open `chrome://extensions`, enable **Developer mode**, choose **Load unpacked**, and select the folder containing `manifest.json`. The **Source code** archives are not the installation package.

## Usage notes

Keep the download manager open until its tasks finish. Recovery depends on available cached files. Original matching supports specific URL formats; website verification, changes and rate limits can affect results.

Processing runs on your device; previews and downloads contact the source websites. See the [user guide](https://github.com/zenvor/image-extractor-extension/blob/v1.0.0/docs/usage.md) and [privacy policy](https://github.com/zenvor/image-extractor-extension/blob/v1.0.0/docs/privacy-policy.md).
