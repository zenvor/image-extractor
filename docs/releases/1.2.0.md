Keep image selections steady while browsing and manage downloads in a clearer, more compact task list.

## Smoother image browsing

- **Keep extracted results while scrolling.** Lazy-loading content no longer clears the current images or interrupts scroll extraction. Refreshing or navigating to a different document still clears outdated results.
- **21 images per page.** Move between pages without replaying checkmark animations or losing selected images.
- **Consistent previews.** Tall images stay inside their thumbnail containers. Failed previews retain a compact Retry preview button in list view.
- **Clearer controls.** Refined backgrounds, spacing, hover feedback and checkbox contrast keep the rounded interface consistent. Saving download speed and extraction options no longer makes the controls fade.

## Simpler actions

- Extract the current page from the main header button, or choose **Scroll and extract** from its dropdown.
- Use the full-width **Copy selected URLs** button and see clipboard confirmation directly on the button.
- Open **Download tasks** from the sidebar; find **Export TXT** under **More**.
- Switch between Chinese and English with one click at the bottom of the sidebar.

## Clearer download tasks

See total, active and saved task counts together, with a unified page background and cleaner progress indicators. Open failure details in a scrollable dialog to read filenames, causes and full URLs without expanding the task row. Failed-only retries and cached download recovery remain available.

## Download and update

Requires **Chrome 120 or newer**.

| File | Purpose |
| --- | --- |
| [Chrome extension ZIP](https://github.com/zenvor/image-extractor/releases/download/v1.2.0/image-extractor-1.2.0-chrome.zip) | Ready-to-load extension package |
| [SHA-256 checksum](https://github.com/zenvor/image-extractor/releases/download/v1.2.0/image-extractor-1.2.0-chrome.zip.sha256) | Verify the downloaded ZIP |

For a first installation, extract the ZIP and load its folder through `chrome://extensions` → **Developer mode** → **Load unpacked**. For an existing unpacked installation, finish active downloads before replacing its files and selecting **Reload**. The **Source code** archives are not the installation package.

Website verification, expired image links and rate limits can still prevent previews, original matching or downloads. This GitHub release does not update the Chrome Web Store package automatically.
