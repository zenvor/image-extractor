# Project descriptions

Repository: `zenvor/image-extractor-extension`

## GitHub About (English)

Extract webpage images and match original URLs from supported thumbnails. Download ZIPs with shared multi-page tasks, adjustable concurrency, failed-only retries, cache recovery, batch URLs, local HTML import, and English/Chinese UI.

## 中文简介

Chrome 图像提取扩展，支持网页采集、缩略图匹配原图、ZIP 批量下载、跨网页任务管理、五档下载策略、仅失败项重试、缓存恢复、批量网址、本地 HTML 和中英文界面。
