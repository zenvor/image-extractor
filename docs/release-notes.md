# Release notes

## [1.2.1 — Clearer controls and searchable download records](releases/1.2.1.md)

Full-width popup actions, a scrollable format popover, startup skeletons, task timestamps, search, status filters and record cleanup. Refreshed bilingual interface screenshots.

[GitHub release](https://github.com/zenvor/image-extractor/releases/tag/v1.2.1)

## [1.2.0 — Smoother image browsing and clearer downloads](releases/1.2.0.md)

Preserved results during lazy loading, steady selections across 21-image pages, streamlined popup actions, and a refined download task list with failure-detail dialogs.

[GitHub release](https://github.com/zenvor/image-extractor/releases/tag/v1.2.0)

## [1.1.0 — Original images from forum links](releases/1.1.0.md)

Image-detail lookup for eleven image-host families used by ViperGirls, with optional site access, saved matches and shared request limits.

[GitHub release](https://github.com/zenvor/image-extractor/releases/tag/v1.1.0)

## [1.0.0 — First stable release](releases/1.0.0.md)

Webpage, batch-URL and HTML extraction; image previews and selection; supported original matching; ZIP downloads with retries and cache recovery.

[GitHub release](https://github.com/zenvor/image-extractor/releases/tag/v1.0.0)

Installation and everyday use are covered by the [README](../README.md) and [user guide](usage.md). Technical verification records live in [release smoke checks](release-smoke.md) and the [image-host guide](hosted-images.md#validation-boundaries).
