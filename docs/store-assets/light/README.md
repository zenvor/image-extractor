## Capture provenance

The candidate extension successfully analyzed the [ISO Republic landscape gallery](https://isorepublic.com/media-category/landscape/) and returned 98 image addresses on 2026-10-30. Six actual first-party landscape results were retained in the isolated session for a readable demonstration, and two were selected. Ads and logos were excluded. The popup displays the page's actual thumbnail sources; the screenshot does not claim original-resolution matching. [Popup capture](popup-source-4x.png): 3200×2400, native 4× rendering.

The [task-list capture](downloads-source-4x.png) is a native 4× rendering at a 1440px viewport. Its completed, partially failed and cancelled tasks are seeded examples, not evidence of actual downloads. Delete and retry labels remain on a single line. Interface text and controls were not repainted. The installed extension was not reloaded; temporary capture permissions apply only to the isolated copy.
