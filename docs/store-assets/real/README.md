# Real-material promotional suite

Created on 2026-10-30 with actual 1.2.1 browser captures, NASA photographs and deterministic typography/compositing. No generative image model or generative upscaling was used.

The popup source is a native 4× capture (3200×2400), showing a curated six-image NASA fixture. The download source is a native 4× capture of the task-list section in a 1440px-wide viewport. The wider viewport keeps Delete record and Retry failed images on one line. Its poster uses a larger full-width table below the headline to preserve readability. These are real rendered controls; no button labels or interface pixels were painted over. Finished, partially failed and cancelled tasks are seeded examples, not download-verification evidence.

Source captures: [popup](popup-source-4x.png), [task list](downloads-source-4x.png). The isolated capture manifest's temporary host grants are not part of the shipped extension; installed extensions were not reloaded.

Photography: NASA, [Artemis II Lunar Flyby](https://www.nasa.gov/gallery/lunar-flyby/). The [5568×3712 original Earthset photograph](https://images-assets.nasa.gov/image/art002e009285/art002e009285~orig.jpg) is cropped and scaled for the posters. The popup also shows NASA images art002e009283, art002e009301, art002e009281, art002e009287 and art002e009298 from that gallery. Images contain no people.
